# React Shopping Website

A responsive E-Commerce Shopping Website built using React.js, Vite, Tailwind CSS, Context API, and React Router.

## Features

- Product Listing
- Product Search
- Category Filtering
- Product Details Page
- Add to Cart
- Update Cart Quantity
- Checkout System
- Order Confirmation
- Responsive UI

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Context API
- React Toastify

## Installation

```bash
npm install
npm run dev
```
